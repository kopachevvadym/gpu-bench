# GPU-бенчмарк до тестового завдання UKRLAW

Перевірка двох тез із технічного рішення на реальному залізі:

1. Скільки часу і памʼяті займає один кліп Wan 2.2 I2V A14B (720p, 5 с) на одній GPU.
2. Що дає sequence parallel (FSDP + Ulysses) на двох GPU без NVLink і яка пропускна здатність NCCL між картами.

## Результати

Прогін ще не виконано. Після запуску тут буде вміст `logs/results.md`.

Час включає завантаження ваг у памʼять, тому прискорення на 2 GPU нижче за чисте прискорення генерації. Кількість кроків зменшено до 20 (офіційно 40), однаково для обох запусків.

## Висновок

[2-3 речення: чи дає друга GPU виграш на цьому звʼязку між картами, скільки памʼяті реально потрібно і як це підтверджує або змінює рішення «одне завдання на одну GPU».]

## Як відтворити

```bash
git clone https://github.com/kopachevvadym/gpu-bench && cd gpu-bench
STEPS=20 ./run_bench.sh
```

Потрібно: 2 GPU по ≥ 80 ГБ, ≥ 250 ГБ диска, Ubuntu з драйвером NVIDIA і Python 3.10+.

## Файли

- `run_bench.sh`: увесь прогін, від nccl-tests до двох запусків Wan 2.2.
- `summarize.py`: зводить логи в таблицю.
- `logs/`: сирі логи, `gpu.csv` (памʼять, потужність, температура щосекунди), `topo.txt`, `results.md`.
